# Telegram Chat через GREEN-API

Тестовое задание: компактный React-интерфейс для отправки и получения текстовых сообщений Telegram через GREEN-API.

## Возможности

- подключение по `apiUrl`, `idInstance` и `apiTokenInstance`;
- проверка состояния инстанса перед входом;
- восстановление списка чатов Telegram при входе;
- просмотр контактов телефонной книги Telegram и открытие чата по выбранному контакту;
- отображение аватаров и уточнение данных личных контактов через `getContactInfo`;
- поиск получателя по телефону или `@username`, а также прямое открытие по `chatId:`;
- отправка текстовых сообщений;
- загрузка до 100 последних текстовых сообщений при первом открытии чата;
- последовательное получение и удаление входящих уведомлений;
- адаптивный интерфейс в визуальной логике Telegram Web;
- состояния загрузки, пустых данных и ошибок.

Исходное задание допускает реализацию для Telegram или WhatsApp, если вариант для MAX недоступен. Этот проект реализует вариант для Telegram.

История загружается однократно при первом открытии чата в текущей сессии. Подгрузки сообщений старше последних 100 и сохранения списка чатов между сессиями пока нет.

## Локальный запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

Перед использованием создайте и авторизуйте Telegram-инстанс в личном кабинете GREEN-API. Значения доступа вводятся в форме приложения и не сохраняются в `localStorage`.

При входе список существующих чатов загружается через `getChats`, а телефонная книга — через `getContacts`. Историю выбранного чата приложение затем запрашивает отдельно.

Сведения и аватары личных чатов подгружаются через `getContactInfo`, когда чат появляется в видимой области списка или открывается. Метод GREEN-API не поддерживает групповые чаты, поэтому для них остаётся инициалы.

Фон окна чата хранится локально в `public/assets/chat_bg-2.80514.png` и подключается приложением по адресу `/assets/chat_bg-2.80514.png`.

## Использованные методы

- `getStateInstance`
- `getChats`
- `getContacts`
- `getContactInfo` (включая аватар)
- `checkAccount`
- `sendMessage`
- `getChatHistory`
- `receiveNotification`
- `deleteNotification`

Получение уведомлений реализовано строго последовательно: приложение читает первое событие FIFO-очереди, обрабатывает его и затем удаляет по `receiptId`.
